# External Integrations

## Vercel Functions

All runtime API handlers live under `api/`. `vercel.json` rewrites public and admin compatibility routes to those handlers.

## Vercel Blob

Write paths:

- `api/admin/uploads.js` creates direct upload tokens through `handleUpload`, imports remote images through server-side fetch, and deletes requested pathnames.
- Admin CRUD endpoints store image URLs/pathnames in Prisma.
- `src/lib/blobCleanup.js` deletes unused managed blobs after updates/deletes.

Read path:

- `api/blob.js` resolves private blobs by pathname and streams or redirects them after checking for an admin session or a public visible database reference.

Supported upload content types are JPEG, PNG, WebP, GIF, and AVIF. Maximum upload/import size is 10 MB.

## YouTube

`src/lib/youtubeChannelSync.js` syncs Crosshair videos from a channel's uploads playlist. It supports:

- API-key mode: `YOUTUBE_API_KEY` plus `YOUTUBE_CHANNEL_ID` or `YOUTUBE_CHANNEL_HANDLE`.
- OAuth mode: `YOUTUBE_CLIENT_ID`, `YOUTUBE_CLIENT_SECRET`, `YOUTUBE_REFRESH_TOKEN`, and optionally `YOUTUBE_CHANNEL_ID`.

OAuth mode is preferred by `auto` sync when configured. Manual edits are preserved for rows whose `source` is not `YOUTUBE_SYNC`.

## SoundCloud

The global player is backed by SoundCloud URLs from public player-pool responses. `src/components/shared/SoundCloudPlayer.jsx` wraps the SoundCloud widget API, and `src/lib/playerContext.jsx` owns playback, queue, loop, shuffle, and full-screen state.

Admin preview can use `privateSoundcloudUrl` for unreleased songs in player contexts. Those URLs are admin-only and should be removed after the release date.

## Spotify and Apple Music

`src/components/shared/SpotifyPlayer.jsx` and `src/components/shared/AppleMusicPlayer.jsx` build embed URLs from release/profile links for public display.

## Vercel Analytics

`src/main.jsx` mounts `<Analytics debug={false} />`.

## Legal Documents

`src/pages/LegalPage.jsx` loads static HTML from `public/legal/terms-of-service.html` and `public/legal/privacy-policy.html`. These legal documents were generated by third-party websites and the checked-in static HTML files are the editable source for this repository.

## Fonts and Static Assets

Custom fonts live in `fonts/`. Bundled images live in `src/assets/` and public static images live in `public/`. The current font files were downloaded for free through DaFont.com; add explicit license/source notes if redistribution requirements need to be tracked.
